# Sky Island Royale

オリジナルのオンライン・バトルロイヤルゲーム。

## 起動方法

Node.jsをインストールしたあと、

npm install

を実行。

その後、

npm start

を実行。

ブラウザで、

http://localhost:3000

を開く。
